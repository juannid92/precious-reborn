# Remix of Cara Preziosi Reimagined

Leggi prima integralmente il file "Lovable-Coscienza.md" e assumilo come protocollo principale di funzionamento del progetto.

Poi analizza il file "lovable-export.zip", che contiene:

- pages/*.md con i contenuti esportati dal sito originale

- assets/uploads con le immagini originali

Il progetto serve a ricostruire e migliorare il sito Cara Preziosi partendo da questi materiali.

Obiettivo:

- ricostruire il sito in modo pulito, moderno e modificabile

- mantenere identità del brand, testi utili, categorie e immagini

- eliminare markup sporco derivato da Elementor

- non clonare il layout vecchio 1:1, ma rifarlo meglio

Ordine di priorità:

1. home

2. categorie

3. anelli

4. servizi

5. storia

6. contatti

Prima di eseguire, segui il protocollo del file Coscienza: leggi tutto, fai piano d’azione, verifica impatti e poi procedi.
